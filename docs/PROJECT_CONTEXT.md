# MaryTour2

## 프로젝트 목적

토키노 메리 생일 기념 팬메이드 모바일 웹게임.

QR, GPS, 스탬프 수집 및 특전 지급 기능을 제공한다.

스토리텔링과 핵심 기능은 독립적으로 관리한다.

## 기술 스택

- React
- Vite
- SCSS
- GSAP
- React Router DOM
- GitHub Pages
- GitHub Actions
- Supabase (예정)
