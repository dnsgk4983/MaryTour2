# Style Architecture

## 스타일 분류

- abstracts: 변수, 함수, 믹스인
- base: 전역 초기화 및 타이포그래피
- layouts: 공통 화면 구조
- components: 역할별 공통 스타일
- utilities: 애니메이션 및 보조 스타일
- pages: 페이지별 배치 및 예외 처리

## 원칙

- 동일한 역할의 클래스는 공통화.
- 페이지마다 동일한 스타일 반복 금지.
- 페이지 SCSS에서 필요한 배치만 수정.
- 사용자 정의 클래스는 언더바 방식.
- 디자인 크기와 위치는 vw 믹스인 사용.
- CSS 자체 문법 및 필수 단위는 예외.
